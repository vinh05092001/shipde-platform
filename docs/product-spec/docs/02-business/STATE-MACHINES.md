## Processing status

Exactly one per waybill snapshot:

- MATCHED
- SOURCE_ONLY
- CARRIER_ONLY
- AMBIGUOUS
- DATA_INCOMPLETE

Findings are separate records and do not form this state machine.

## Settlement batch

Two independent dimensions:

Carrier transfer:

- NOT_REPORTED
- REPORTED

Bank reconciliation:

- NO_DATA
- UNMATCHED
- MATCHED_FULL
- RECEIVED_SHORT
- RECEIVED_OVER

Carry-forward is a case-period link, not a case state.
