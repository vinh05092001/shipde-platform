## Business outcome

Live isolated `cli.js orchestrate` runs previously lacked `jevAsk` wiring from `sources.json`, sent uncapped combo member lists to JEV, and could hit `ECONNRESET` when reusing a pooled HTTP keep-alive socket after a blocking `spawnSync` worker run. This Work Item wires `jevAsk`, `jevMinConfidence`, and `jevMaxOptions` in `orchestrateCommand` (while preserving `strictIndependentComboReview`), caps JEV options with effort diversity via `shortlistForJev` (without shrinking the deterministic fallback pool), and sets `agent: false` in `jev.js` so each JEV request uses a fresh socket.
