## Business rules and edge cases

- `DEC-016` / `ADR-001`: the committed result is a TypeScript monorepo with one lockfile and shared package boundaries; a directory-only move without root orchestration is insufficient.
- Behavior preservation is bidirectional: all baseline-protected surfaces, role sets, modal openers, route handlers, deterministic engines, error codes, and fixtures must remain, and the migration must not add or silently activate previously absent behavior.
- Current mock, simulated, hard-coded, client-only, and in-memory behavior remains truthfully labeled. Relocation may not convert evidence classifications or present mock carrier actions as live.
- Package installation must be reproducible from a clean checkout using the committed pnpm lockfile and must fail on lockfile drift. npm and pnpm lockfiles may not coexist after migration.
- Dependency lifecycle scripts are denied by default; an allowlist entry requires an identified package, reason, and review evidence. Blanket approval is prohibited.
- All root tasks must fail if a required child task fails. Turbo filters, cache hits, or an empty package match may not turn missing verification into success.
- The formatter and Gitleaks checks retain their exact fail-closed behavior across renamed paths, including safe negative fixtures and guaranteed cleanup.
- A Windows path, CRLF line ending, clean Linux CI checkout, path containing spaces, or absent global `pnpm`/`turbo` copy must not change repository semantics. The exact repository-pinned package manager remains authoritative.
- No changed import path may create a client/server boundary leak or expose server-only, credential, PII, or adapter code through a browser/shared package.
- If a move breaks Next.js route discovery, CSS/font loading, path aliases, Prisma generation, or test fixture discovery, the migration must repair the structural reference without changing the underlying behavior.
- If an existing baseline check cannot be preserved without a product, schema, security, or UX change, mark the item `BLOCKED` with evidence; do not weaken or delete the check.
