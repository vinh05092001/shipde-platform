## Business outcome

Previously, `buildJevAsk` sent the retired `weightProfile` question key and identical generic criteria strings (`Choose M0 when it best fits the supplied state.`) for every `M0..Mk` option in `select-combo-member`. This Work Item sets the default `questionKey` for `select-combo-member` to `comboMember` (while preserving explicit `question.key` and legacy defaults), generates purely factual per-option `criteria` from `tier`, `score`, `effort`, and `priorUnknown` without leaking model/provider/account/raw Work Item identities, and makes `normalizeAdvice` fail closed when a `select-combo-member` response carries an `answers` map missing or mis-typing the named entry.
