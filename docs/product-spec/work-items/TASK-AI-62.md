## Business outcome

Five newly configured model sources (Cohere, Baseten, Inception, Regolo, AMD Radeon Cloud) and one compromised source (Dahl) are imported into the Controller's source registry and discovery evidence with honest, never-promoted proof levels. A direct HTTP nonce proves only that the vendor answered (`API_PASS`); a nonce returned through OpenCode/Paseo proves the harness route (`HARNESS_PASS`, exactly one representative model per source, the supervisor's baseten `zai-org/GLM-5.3` observation `HARNESS-OK-8K2` on 2026-09-28); real work plus review remains `WORK_ITEM_PASS`. Nothing in the pipeline may promote a lower level to a higher one, and a compromised credential is recorded but never used.

## Preconditions and dependencies

- `TASK-AI-58` (Controller MVP) is merged: it owns candidate selection, evidence, ranking and dispatch. This Work Item only feeds it data.
- The direct-HTTP probe pass and the supervisor's HARNESS_PASS observation exist as secret-free input files.

## In scope

1. Registry entries for the five new sources plus the deferred Dahl entry (`disposition: deferred`, `dispositionReason: COMPROMISED_CREDENTIAL`), credentials referenced by env var name only.
2. Honest proof levels in the evidence store: `ProofLevel` (`API_PASS` / `HARNESS_PASS` / `WORK_ITEM_PASS`), `proofLevelOf`, `isHarnessProven`; numeric evidence levels map to their proof level, never above it.
3. `discovery.js import probe-pass`: imports the probe result file plus the recorded harness passes into committed evidence, one candidate per (source, model) with source, access path, model id for that path, timestamp, latency, proof level, status, error class, failure scope and a secret-free raw-evidence reference.
4. Deferred sources are refused everywhere: no generated candidates, no enumeration (not even a models listing, which would use the compromised credential), dispatch refusal with reason, and no HARNESS_PASS.
5. The discovery read interface exposes each candidate's strongest honest proof level.

## Out of scope

- Running any live probe; the import is data-driven from the existing secret-free evidence files.
- Any change to the Controller's selection policy or ranking weights.
- Pushing, opening a Pull Request, merging, or any GitHub write.

## Business rules

| Rule        | Behavior                                                                                                                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AI-62-R01` | Proof levels are honest and one-way: API_PASS (direct HTTP nonce), HARNESS_PASS (nonce through OpenCode/Paseo), WORK_ITEM_PASS (real work plus review). API_PASS is never promoted.         |
| `AI-62-R02` | Candidate identity is harness+accessPath+gateway+upstream+account+quotaScope+modelId; the HTTP alias and the OpenCode alias are separate candidates; two accounts on one upstream never merge. |
| `AI-62-R03` | One representative HARNESS probe per source; only those carry HARNESS_PASS; every other imported model stays API_PASS.                                                                     |
| `AI-62-R04` | Dahl is DEFERRED / COMPROMISED_CREDENTIAL: recorded for audit, never enumerated, never dispatched, never harness-proven.                                                                    |
| `AI-62-R05` | No source or model list is hard-coded in logic; discovery and import are driven by `sources.json`, the probe file and the harness-passes file.                                              |
| `AI-62-R06` | No credential value is ever read, printed, stored or committed; only env var names are referenced.                                                                                         |
| `AI-62-R07` | Failure evidence keeps its cause class and scope: 429, 402, 401, timeout and capacity remain distinct causes with their own scopes.                                                          |
