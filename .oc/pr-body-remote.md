## Implementation

- UI and user states:
  - Data table: Loading skeleton (`aria-busy="true"` with 6 placeholder rows), accessible empty state with reset filter CTA, dedicated 403 Forbidden state with `role="alert"`, `ShieldAlert` icon, and recovery action button, error banner (`role="alert"`) with "Thử lại" retry action, and loaded interactive table with keyboard accessibility and sticky headers inside a bounded scroll container (`data-testid="table-scroll-container"` with `max-h-[600px]` and `overflow-y-auto`).
  - Column header: `DataTableColumnHeader` supporting ascending, descending, and unsorted states with `aria-sort` ('ascending' | 'descending' | 'none'), trigger focus restoration on dropdown dismissal, and keyboard arrow-key navigation across menu items.
  - Pagination: `DataTablePagination` with Vietnamese localization ("Hiển thị X-Y trên Z bản ghi"), page size selector (10, 20, 50, 100), selection counter, safe clamping for out-of-range deep links preventing inverted record counts, and accessible buttons.
  - Toolbar & Faceted Filter: `DataTableToolbar` with search clear button (`title="Xóa nội dung tìm kiếm"`), `DataTableFacetedFilter` with optimistic selection accumulation queue (`computeOptimisticFacetSelection`) that preserves newer selections during delayed commits and explicitly clears pending selections on reset signal (`resetEpoch`), trigger focus restoration on dismissal, listbox arrow-key keyboard navigation, and `DataTableViewOptions` for column visibility with localized Vietnamese labels, trigger focus restoration, and keyboard navigation.
  - URL synchronization hook: `useDataTable` establishing a pure single source of truth from committed router search parameters (`useSearchParams()` or `props.searchParams`). Eliminates `historyEpoch`, `popstate` event listeners, `window.location.search` memoization snapshot, and internal pending queue. Table interactions exclusively push URL search parameter updates via `router.push`/`onNavigate`, while `DataTableToolbar` debounces user search input text drafts via `createDebouncedSearch` without mutating committed state.
  - Dashboard shell: `DashboardLayout` responsive layout with desktop collapsible sidebar, mobile drawer overlay with focus trap (`handleDrawerKeyDown`) and focus restoration, permission-filtered navigation via `filterNavSectionsByPermissions` and `isNavItemPermitted` denying administrative routes to absent or empty-permission users, clean `DEFAULT_NAV_SECTIONS` without hardcoded operational badges, `DashboardSidebar` (width 260px expanded, 72px collapsed) with accessible empty navigation fallback, `DashboardHeader` with mobile hamburger trigger, current shop badge, global Ctrl+K search trigger, explicit unauthenticated state handling when user data is null, user menu with focus restoration, and `PageHeader` with breadcrumbs and action slots.
  - Storybook showcase page: `apps/web/src/app/storybook/page.tsx` demonstrating all components and interactive state simulator (Normal, Loading, Empty, Error, Forbidden 403), connected primary actions (export fixture CSV and create demo shipment), select-all with current-page membership validation using isolated `fix-` fixture data (`FIXTURE_SHIPMENTS`), operational badges isolated in `SHOWCASE_NAV_SECTIONS`, and page index clamping on out-of-range deep links.
- API/application behavior: Pure reusable client UI components; no server route modifications.
- Data/migrations: N/A — no database tables or migrations modified.
- Permissions/tenancy/audit: N/A — client presentation layer; displays masked fixture phone numbers and integer VND currency without floating-point arithmetic.
- Upstream MIT license notices: Preserved in full headers on all ported component modules.
